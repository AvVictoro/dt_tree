# DataTracker: каталоги

Отдельный проект для сравнения вариантов навигации по каталогу индикаторов. Исходная оболочка перенесена из `AvVictoro/DTTTT`; дальнейшая разработка ведётся независимо в `AvVictoro/dt_tree`.

## Локальный запуск

```bash
npm install
npm run dev
```

По умолчанию приложение открывается на `http://127.0.0.1:4173/`.
